# Raw Transcripts

The raw English transcripts these notes were built from — one `.txt` file per lecture session, named `<date>-<session>.txt` (e.g. `apr07-02.txt` = April 7th, second session of the day).

**How these were produced:** the original lectures were recorded in Telugu. Each file here is the direct output of local speech-to-text (Whisper, running the `translate` task), which transcribes and translates straight to English in one step — no LLM/AI involved in this step. As raw ASR output, expect:
- Run-on, unpunctuated, conversational text (classroom chatter, filler words, cross-talk included).
- Occasional mistranscribed technical terms (e.g. "Unipoint Studio" → should read "Anypoint Studio", "transfer message" → "Transform Message", "floor" → "flow"). These are corrected in the polished notes but left as-is here since this folder preserves the raw transcription.

**Where to actually read/learn from these lectures:**
- [../](../) — concise notes, one file per date.
- [../detailed-notes/](../detailed-notes/) — deep, example-rich, diagram-heavy notes per date.

These raw files are kept for reference/traceability (e.g. to double-check a detail against the original wording), not meant as the primary way to consume the material.
